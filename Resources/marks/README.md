# Optional local agent marks

Third-party application artwork is not distributed with Antarium. The app uses
vector or initial-letter fallbacks when a configured PNG is absent.

For local development only, `tools/extract-icons.sh` can derive monochrome marks
from applications installed on your Mac. Generated PNGs in this directory are
ignored by Git and must not be submitted in pull requests or release source.
